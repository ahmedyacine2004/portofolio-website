# SEO and Discoverability Guide

The portfolio should be optimized for search engines, social sharing, and accessibility.

## Metadata

Use meaningful page titles, descriptions, and Open Graph metadata for each route. The app already uses metadata configuration in the root layout and should be extended as new pages are added.

## Content structure

- Use descriptive headings.
- Keep page content concise and meaningful.
- Ensure each section has a clear purpose.

## Accessibility and performance

SEO also benefits from:

- semantic structure
- strong contrast
- efficient page performance
- responsive layouts
- descriptive link text

## Recommended improvements

As content grows, continue improving:

- page-specific metadata
- internal linking between sections
- structured content for projects and services
- image alt text and accessible labels
